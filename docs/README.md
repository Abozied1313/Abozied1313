# تقرير طفرات الذكاء الاصطناعي 2025-2026

هذا المجلد يحتوي على نسخة HTML جاهزة للطباعة من التقرير العربي:

- [`ai-report-2026.html`](./ai-report-2026.html)

## التحويل إلى PDF

للحصول على ملف PDF:

1. افتح `docs/ai-report-2026.html` في Chrome أو Edge.
2. اختر **Print** أو اضغط `Ctrl+P`.
3. اختر **Save as PDF**.
4. فعّل خيار **Background graphics** حتى تظهر الألوان والتنسيقات.
5. احفظ الملف باسم `ai-report-2026.pdf`.

> ملاحظة: تعذر توليد PDF تلقائياً داخل بيئة التنفيذ الحالية لأن أدوات التحويل مثل Chromium / wkhtmltopdf / WeasyPrint غير متوفرة، ومحاولة تثبيت الحزم عبر الشبكة رُفضت من الوكيل.
